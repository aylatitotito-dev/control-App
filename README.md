# AppControl - Instalador para Windows

Esta rama solo guarda el instalador. El código fuente está en la rama `main`.

## Descargar e instalar

1. Abre el archivo `AppControl-0.0.1.exe` de esta rama.
2. Pulsa **Download raw file** (el icono de descarga, a la derecha).
3. Haz doble clic en el archivo descargado. Si Windows muestra «Windows protegió su PC», pulsa **Más información** y **Ejecutar de todas formas**.
4. Sigue el asistente: Next, aceptar los términos, Next, Next, Install, Finish.

No pide permisos de administrador y ya incluye Java. Si hay una versión más nueva, la aplicación se actualiza sola.
